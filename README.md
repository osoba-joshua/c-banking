Secure C-Banking System

A robust, terminal-based banking application written entirely in C. This project was built to demonstrate foundational systems-level programming concepts, including manual dynamic memory management, cryptographic hashing, file encryption, and input sanitization.

✨ Features

Custom ANSI User Interface: Provides a clean, dynamic, full-screen terminal UI with color-coded prompts and status messages.

Encrypted File Persistence: Database records are encrypted using an XOR cipher and Hexadecimal encoding before being written to disk, preventing plaintext data exposure.

Cryptographic PIN Hashing: Implements the DJB2 hash algorithm for one-way PIN encryption. The system verifies PINs against the hash, ensuring passwords are never stored in plain text.

Dynamic Memory Allocation: Utilizes pointers, malloc, realloc, and free to dynamically scale the in-memory database to accommodate an infinite number of accounts without hard-coded limits.

Input Sanitization & Buffer Flushing: Safely handles edge cases (like typing letters into a number prompt) to prevent infinite loops and buffer overflow vulnerabilities.

🛠️ Technical Architecture

Memory Management (Load-Modify-Save)

The system operates using an efficient Load-Modify-Save paradigm:

Load: On startup, the encrypted text file is decrypted and loaded into a dynamically allocated array.

Modify: Transactions (deposits, transfers, account creation) manipulate this in-memory data structure. If the array reaches capacity, realloc safely expands it.

Save: Upon any modification, the updated array is re-encrypted and writes over the old database file, ensuring persistent state even in the event of a crash.

🚀 Getting Started

Prerequisites

A C Compiler (GCC, Clang, or MSVC)

Windows environment (due to <windows.h> usage for terminal clearing)

Compilation & Execution

To compile the application as a standalone executable (packing necessary libraries so it runs smoothly on any Windows machine), run the following command in your terminal:

gcc bank_ui.c -o SecureBank.exe -static


Then, run the compiled executable:

SecureBank.exe


📂 File Structure Note

bank_db.txt: This file is automatically generated upon running the program and creating your first account. It holds the encrypted state of the bank. It is intentionally added to the .gitignore so personal test data is not uploaded to version control.
